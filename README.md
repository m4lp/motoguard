# 🏍️ MotoGuard

Sistema de gerenciamento para oficinas ou frotas de motocicletas, focado em operações CRUD eficientes e persistência de dados segura.

## 🛠️ Tecnologias Utilizadas
*   **Java 21**
*   **Spring Boot 3**
*   **Spring Data JPA**
*   **MySQL** (Banco de dados relacional)
*   **Maven** (Gerenciador de dependências)

*   ## 🚀 Funcionalidades
- [x] Cadastro de motocicletas (Marca, Modelo, Ano, Placa).
- [x] Listagem completa de veículos.
- [x] Busca detalhada por ID.
- [x] Exclusão de registros do sistema.

## ⚙️ Como executar o projeto
1. Clone o repositório.
2. Configure o banco de dados no `application.properties`.
3. Execute `./mvnw spring-boot:run` ou pela sua IDE de preferência.
